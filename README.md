# Módulo de Autenticación — EquipoN

## Objetivo
Desarrollar un módulo de autenticación que permita a los usuarios
registrarse, iniciar sesión y acceder a un dashboard personalizado.

## Historias de Usuario

| ID | Historia |
|----|----------|
| HU-1 | Como usuario registrado quiero iniciar sesión con mi correo 
y contraseña para acceder al panel de control. |
| HU-2 | Como nuevo usuario quiero registrarme con mis datos básicos 
para crear una cuenta y acceder al sistema. |
| HU-3 | Como usuario autenticado quiero visualizar un dashboard 
para tener una vista general del sistema. |
